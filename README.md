# line-stamp-lp

AIで作る「売れるLINEスタンプ」を、スマホだけで販売申請するまで解説する、Instagram特典配布LPです。
[lp-template](https://github.com/ryooh18-byte/lp-template) をもとに作成しています。

`index.html` 1ファイル（CSS・JS内蔵）＋ `assets/` で完結します。

## 内容

| 場所 | 内容 |
|---|---|
| はじめに | 売れない原因（挨拶ばかり）と、売れるコツ（職場の専門用語を中心に、基本の挨拶も混ぜる） |
| 準備 | LINEスタンプメーカーのインストールとクリエイター登録（番号なし） |
| STEP 1 | ChatGPTでプロンプト①を送り、職業の候補→セリフ45個→選んだ9個をコードブロックで受け取る |
| STEP 2 | プロンプト②で、スタンプ9個を正方形の1枚（3列×3行・背景透明）にまとめて作る。個数のルール、審査で落ちやすいものも掲載 |
| STEP 3 | LINEスタンプメーカーで、1個ずつ正方形に型抜き → 8個そろえて販売申請（販売情報の設定を含む）→ 審査 → リリース |
| 売上の受け取り | 取り分（手数料30%を除いた50%）・受け取りの条件・口座登録の注意書き（手順は載せない）（番号なし） |
| 補足 | つまずきやすいところ／こんなとき、どうする？の表 |

STEPは1〜3だけです（動画の①②③と同じ3ステップ）。「準備」と「売上の受け取り」には、番号をつけていません。

## 確認した情報（2026年10月）

- アプリの手順は、ご本人の画面録画（73秒）で確認：スタンプ→画像を選ぶ→スキップ→切り抜き→正方形→位置を微調整→次へ→次へ→完成イメージ→保存→タイトル→販売申請→8個を選ぶ→メイン画像→販売情報→プレビュー→権利の確認→リクエスト
- 販売情報の初期状態は「ショップ非公開」「売上分配額なし」。販売するには、「LINE STORE／ショップ公開」「有料ダウンロード／売上分配額あり」に変える（LINE公式ヘルプ：売上の分配は、申請時にこの設定を選んだスタンプだけ。アプリで公開／非公開を選べるのは申請時だけ）
- 販売開始の初期設定は手動で、承認のあとにリリースの操作が必要（LINE公式ヘルプ）
- 分配は手数料30%を除いた売上の50%／最低1,000円／約45日以内／振込手数料は本人負担（LINE Creators Market 公式）
- プロンプト①②は、看護師で試して動作を確認（①はパソコンとスマホ、②は正方形版で、9個が離れて並び、背景が透明になることを実測）
- 販売価格は金額を書かず、「いちばん安い価格」とする
- 出典：creator.line.me（ご利用方法・ガイドライン・審査ガイドライン・利用規約・LINEスタンプメーカー）、help2.line.me/creators（ヘルプ）

## 注意

- 実例の推定の金額は、ハートの数 × 価格（190円）で出した目安です。
- 「売れているスタンプの例」の画像は、他の方の作品のLINE STORE画面です（スタンプ名と制作者名は、画像でぼかしています）。
- LINE Creators Marketの規約や手数料は変わることがあります。最新の内容は、公式で確認してください。

## 固定部分から変更した点

このLPだけの変更です。`lp-template` や他のLPは変えていません。

- お礼・自己紹介の1行目を、「この特典を受け取ってくださり」から「このページを見ていただき」に変更（上のバナーの「特典」と紛らわしいため）
- 「そんな方のために✨」のあとのバナーと、いちばん最後のCTA（バナー・説明文・ボタン）を削除（受け取りの誘いが続いて、しつこく見えるため）。特典の誘いは、いちばん上のバナー、締めのメッセージカードのバナー、スマホ下部の固定ボタンの3つ
- 締めのメッセージカードの「公式LINEで無料で受け取る」ボタンを、バナーに変更。「を無料で受け取れます」を「を受け取れます」に変更し、バナーの下に「相談会も無料でやっています。こちらのLINEから特典を受け取り、お申込みください。」を追加
- 「そんな方のために✨」の前のつなぎ文に、「もっと大きく収入を得たい」「もっと学んでみたい」の2行を追加（2026-10-29、ユーザーの指示）
- 締めのメッセージカードの見出しを、「AIワーク0-1達成 スタートブック」から「AIワーク0-1達成 スタートブックを無料プレゼント☆」に変更（2026-10-29、ユーザーの指示）
- 締めのメッセージカードのバナーの下に、枠つきのボタン「タップして受け取る👆」を追加し、LINEのリンクを設定（2026-10-29、ユーザーの指示。リンク先は他のLINE誘導と同じ）
- スマホ下部の固定ボタンは、最初のバナーが見えなくなってから出し、締めのメッセージカードに着いたら、そのあとは出さない
